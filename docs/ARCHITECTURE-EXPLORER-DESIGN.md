# Model Architecture Explorer Design — Feature 2

Status: **approved for implementation.** Component names, symbols, and line ranges were read from `dipeshdarks/DipAi` at commit `9d4de6b` and are re-verified at artifact-generation time (procedure in §5).

## 1. Objective

An interactive visualization of **DIPAI's real architecture** — the decoder-only `DipaiGPT` actually implemented in `dipai/model.py` — with verified metadata, parameter counts measured from real tensors, and links that open the actual source. No conventional-Transformer embellishments that the code does not contain (e.g. no RoPE block, no KV-head grouping, no cross-attention — none exist here).

## 2. Actual architecture (verified inventory)

Forward path of `DipaiGPT` (`dipai/model.py:120`, `forward` at 176):

| # | Component | Class / op | Evidence (commit `9d4de6b`) |
|---|---|---|---|
| 1 | Token input | token ids `(B, T)` int64 | `forward` docstring, `model.py:181` |
| 2 | Tokenizer interface | SentencePiece BPE, fixed specials pad/unk/bos/eos = 0/1/2/3 | `dipai/tokenizer.py:23–26`, `encode/decode` 81–100 |
| 3 | Token embedding | `nn.Embedding(vocab_size, n_embd)` (`tok_emb`) | `model.py:128` |
| 4 | Positional embedding | **learned absolute** `nn.Embedding(block_size, n_embd)` (`pos_emb`), added elementwise | `model.py:129`, `add` at 189 |
| 5 | Dropout | `nn.Dropout(dropout)` on the sum | `model.py:130`, `model.py:189` |
| 6 | Transformer block ×`n_layer` | pre-LN `Block`: `x + attn(ln1(x))`, `x + mlp(ln2(x))` | `model.py:100–113` |
| 6a | ├ LayerNorm | `ln1` (`nn.LayerNorm`, bias = `cfg.bias`) | `model.py:105` |
| 6b | ├ Attention | `CausalSelfAttention`: fused `qkv` Linear `E→3E`, split q/k/v, reshape heads, `F.scaled_dot_product_attention(is_causal=True)`, out `proj` `E→E`, residual dropout | `model.py:38–80` |
| 6c | ├ LayerNorm | `ln2` | `model.py:107` |
| 6d | └ MLP | `fc` `E→4E`, `GELU`, `proj` `4E→E`, dropout, residual | `model.py:87–97` |
| 7 | Final LayerNorm | `ln_f` | `model.py:132`, applied at 197 |
| 8 | LM head | `lm_head` Linear `E→vocab_size`, no bias; **weight-tied to `tok_emb` when `cfg.tie_weights`** (default true) | `model.py:133`, tie 135–136 |
| 9 | Logits | `(B, T, vocab_size)`; CE loss vs shifted targets, `ignore_index=-100` | `model.py:199–206` |
| 10 | Generation | external sampling loop (`dipai/generate.py:103`) with temperature/top-k/top-p/rep-penalty | `generate.py` |

Not present (explicitly, to avoid diagram hallucination): rotary/relative position encodings, KV-head GQA/MQA, attention biases, scale/residual variants other than pre-LN, MoE, convolutions, layer scale, auxiliary heads.

Parameter group partition (exhaustive, over `model.named_parameters()` which **de-duplicates tied weights** — verified behavior reused from `scripts/estimate_model.py:46`):

```
tok_emb.*            → token_embedding
pos_emb.*            → position_embedding
blocks.<i>.*         → transformer_blocks   (attn qkv/proj, mlp fc/proj, ln1/ln2)
ln_f.*               → final_ln
lm_head.*            → lm_head_untied       (0 params when tied)
sum(partition) == model.num_params  (asserted in tests, both tie modes)
```

`model.num_params` and `num_params_nonembed` are computed in `DipaiGPT.__init__` (`model.py:145–150`) from real tensors — the explorer reports those exact numbers, distinguishing **total** vs (when tied) **non-embedding** counts. Trainable vs frozen: 100 % trainable for scratch checkpoints (no `requires_grad=False` anywhere in `model.py`); for imported artifacts from other sources the field is computed from tensors (`p.requires_grad`) and shown as such.

## 3. Metadata artifact (`dipai-archmeta/1`)

Generated by `python -m dipai.archmeta`:

```
--config configs/scratch.yaml            # config source (no checkpoint read)
--checkpoint data/checkpoints/<dir>      # model_config from payload (weights NOT loaded;
                                         #  torch.load map_location="cpu" then payload dropped)
--config + --checkpoint                  # config wins for building; checkpoint recorded as
                                         #  provenance and mismatch (if any) as a warning
-o <path>.json
```

**Source-of-truth precedence & provenance:** `source: { kind: "config"|"checkpoint", path, sha256? }`; when both given, `model_config` comes from the checkpoint payload (it is what the artifact describes) and the config file is recorded. Build path: `ModelConfig(**model_config)` → `build_model()` (validates dims, `config.py:43`).

Artifact fields (abridged; the Zod schema in `lib/diplens/schemas.ts` is the mirror):

```
schema, schema_version: 1
generated_at (ISO-UTC), generator: { dipai_git: { head, origin_main?, dirty, anchors_verified: bool } }
source: { kind, path_display, sha256? }
model: { class: "DipaiGPT", model_config: {vocab_size, block_size, n_layer, n_head, n_embd,
          dropout, bias, tie_weights}, head_dim (= n_embd/n_head),
         positional_encoding: "learned_absolute", normalization: "pre_layernorm",
         activation: "gelu", attention: "sdpa_causal_fused_qkv",
         max_context: block_size, vocab_source: "model_config" }
params: { total, nonembed?, trainable, frozen,
          components: [ {id, label, count, pct} ... exhaustive ],
          tie_note?: "lm_head.weight tied to tok_emb.weight (counted once)" }
shapes: { batch, seq (observed T), note: "observed via forward on CPU with zero ids" ,
          nodes: { node_id: { input?: [...], output?: [...], params?: {name: [...]} } } }
components: [ { id, kind: "io"|"embedding"|"block"|"attention"|"mlp"|"norm"|"head",
                label, purpose, params?, config: {...}, in_out?: {input, output},
                connections: [ids], source: { file, symbol, lines: [start, end],
                                              url?, verified: bool, note? } } ]
flow: [ { from, to, label } ]            # ordered, edge list for the graph
warnings: [ ... ]                        # e.g. source verification degraded, ckpt/config mismatch
```

**Numbers policy:** `params.*` only from instantiated tensors (`model.num_params` / per-group sums); `model_config.*` exactly as parsed; `shapes.*` only from the observed forward or `null`; `head_dim` computed and cross-checked (`n_embd % n_head == 0` enforced by `ModelConfig.validate`). Anything unverifiable → `null` + label, never a placeholder number.

**Build cost guard:** default configs are ≤ ~50 M params (CPU build ≈ 200 MB, sub-second). For extreme configs (> ~1 B) the utility refuses with guidance unless `--allow-large-build` (documented) — meta-device builds (as in `scripts/estimate_model.py`) still support parameter counting without shapes (`shapes: null`, warning recorded).

## 4. Observed shapes (safe dummy forward)

- Build on CPU, `model.eval()`, `torch.no_grad()`; input `torch.zeros(1, T)` with `T = min(8, block_size)` (zeros = `<pad>` id, always in-vocab).
- Capture per-component in/out shapes with **forward hooks** on: `tok_emb`, `pos_emb`, each `blocks[i].ln1/attn/ln2/mlp`, `ln_f`, `lm_head` (plus top-level logits).
- Output recorded verbatim (e.g. `lm_head.output = [1, 8, vocab_size]`), plus param tensor shapes (`qkv.weight = [3E, E]`).
- Template shapes with symbolic `B,T` are derived analytically and shown as captions; **observed** shapes are the evidence-backed primary values; both are labelled.
- CPU only — no CUDA requirement, no device-side allocations beyond weights.

## 5. Source links (real or none)

Anchors are `(file, symbol, lines)` pairs. Initial map (commit `9d4de6b`, re-verified at generation):

| id | file | symbol | lines |
|---|---|---|---|
| tokenizer | `dipai/tokenizer.py` | `class DipaiTokenizer` | 42–262 |
| tok_emb / pos_emb / blocks / ln_f / lm_head / tie | `dipai/model.py` | `DipaiGPT.__init__` | 120–150 (tie: 135–136) |
| forward / loss | `dipai/model.py` | `DipaiGPT.forward` | 176–211 (loss 199–206) |
| attention | `dipai/model.py` | `class CausalSelfAttention` | 38–80 |
| block | `dipai/model.py` | `class Block` | 100–113 |
| mlp | `dipai/model.py` | `class MLP` | 87–97 |
| final_ln | `dipai/model.py` | `DipaiGPT.__init__` (`ln_f`) | 132–132 |
| generate | `dipai/generate.py` | `def generate` | 103–163 |
| loss-objective config | `dipai/config.py` | `class ModelConfig` | 31–72 |

**Verification procedure at generation time (all must pass → `verified: true`):**

1. local file exists and has ≥ `lines.end` lines;
2. the `symbol` (class/def declaration) appears within the range;
3. the file exists in the pushed tree: `git cat-file -e origin/main:<file>` (DIPAI changes are additive-only, so pushed anchors for pre-existing files stay valid);
4. URL built as `GITHUB.blob(file) + #L<start>-<end>` (helper: `lib/docs/registry.ts`, repo `dipeshdarks/DipAi`, branch `main`).

On failure: `url: null`, `verified: false`, `note` explaining the fallback — **the UI never fabricates a link**; it shows `file:symbol` text plus the artifact's `source_commit` so a human can locate it. The artifact records `anchors_verified` globally.

## 6. DIPLens Architecture Explorer (UI)

Route `app/architecture` (client component; nav label **Architecture Explorer**):

1. **Source of view:** bundled `lib/generated/architecture.json` (generated from `configs/scratch.yaml` — documented one-command regeneration; committed like the docs search index so it works on Vercel with zero runtime fs) or user-imported artifact (file input, Zod, 2 MB cap) with a provenance banner (`source.path_display` + `generated_at` + git head).
2. **Model summary panel:** architecture/class, total parameters (`num()`-formatted; `—` for null), non-embedding count when distinct, trainable/frozen, `n_layer`, `n_head` + `head_dim`, `n_embd`, FFN width (`4 × n_embd` — stated as implemented), `block_size` (context), `vocab_size` with an explicit label **“model embedding-table vocabulary”** (kept distinct from any tokenizer vocabulary; tokenizer vocab shown separately as `tokenizer.vocab_size` when present in the artifact), positional encoding, normalization, tying, dropout/bias. Each block carries a small provenance chip: `config` / `tensors` / `observed`.
3. **Graph (`ArchGraph`):** layered top→bottom (left→right on wide screens): `flow` edges rendered as HTML nodes + SVG connectors; **no new dependencies** (no react-flow/mermaid for this — the graph is a fixed layered DAG, custom markup keeps it responsive and testable). Nodes are `<button>`s: hover/focus highlight, `aria-label` with label+params, Enter/Space selects → **detail panel**. Zoom/pan omitted deliberately (diagram fits viewport; documented decision, “if appropriate” clause). Mobile: single-column stack, connectors hidden (`aria-hidden`), identical information order.
4. **Accessibility fallback:** a permanent `<ol>` **text view** (`ArchSummary` list) mirrors every node's data — the explorer is fully usable with graph rendering unavailable (no-JS/JS-disabled edge: the page ships the ordered list server-rendered… page is client-rendered; the list renders as soon as data hydrates and is the semantic default inside the same component tree; tests assert list + button roles).
5. **Component detail panel:** purpose text, verified parameter count + pct, in/out shapes (observed), relevant config values (e.g. attention: `n_head`, `head_dim`, `is_causal: true`, fused qkv), connection list (“receives from →, feeds →”), source row: `file:symbol Lstart–end` + GitHub link (when `verified`) or truthful fallback note, implementation notes (e.g. “weights tied — 0 additional parameters”).
6. **Parameter breakdown:** table (component, count, %, tie note) + Recharts horizontal bar chart from the same artifact numbers; footer asserts reconciliation `Σ = total` (computed client-side from artifact data — if an imported artifact's sums mismatch, an integrity warning is shown instead of the chart).
7. **States:** loading (import parse), empty (no artifact bundled — defensive), error (parse/shape failure with message), unsupported (`schema_version` mismatch → dedicated panel naming the required version).

## 7. Testing (Feature 2)

DIPAI (`tests/test_archmeta.py`):

- tiny config artifact: `params.total == model.num_params`; component sum == total (tie **on** and **off** parametrized); `nonembed` matches `num_params_nonembed`;
- shapes: `tok_emb.output == [T, E]`-style observed shapes match config (`T = min(8, block_size)`); `lm_head.output[-1] == vocab_size`;
- all flow node ids referenced by `flow`/`connections` exist in `components` (graph integrity);
- **anchor verification:** for every component, local file exists, line range within file length, symbol found in range — run against the real repository files (regression: fails if someone edits `model.py` and shifts anchors without regenerating);
- checkpoint source: artifact built from a saved tiny checkpoint payload matches config-built artifact (`model_config` equality, source.kind == "checkpoint");
- config strictness: unknown model key in YAML → clean error (existing behavior surfaced);
- meta-device path: `--allow-large-build` off + big synthetic config → params counted, `shapes: null`, warning present;
- shared fixture written for DIPLens validates against the Python-side shape assertions.

DIPLens (`lib/diplens/schemas.test.ts`, `components/explorer/*.test.tsx`):

- Zod: accepts `dipai-archmeta/1` fixture; rejects version 99 / wrong schema; tolerates unknown fields;
- render: summary shows measured total (formatted), vocab label present, `—` for any null field (never `0`);
- graph: node buttons focusable (tab order), selecting opens detail with `file:symbol`, link `href` matches `https://github.com/dipeshdarks/DipAi/blob/main/<file>#L<a>-<b>` when `verified`, and renders text fallback when `verified: false`;
- breakdown: component sum equals displayed total (integrity test from fixture); tied artifact shows the tie note and `lm_head` count 0;
- import: valid artifact replaces bundled view + banner; invalid file → error state; future version → unsupported state;
- regression: existing 144 tests unchanged.

## 9. Explicit non-goals

- No duplicate model implementation in TypeScript (metadata only, per integration plan).
- No live parameter introspection from the browser; no weights shipped to DIPLens.
- No speculative components beyond the verified inventory (§2).
- No fabricated line numbers, links, or “estimated” counts when tensors exist.
